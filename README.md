# Déploiement Netlify
1. Mettez ce dossier sur GitHub (nouveau dépôt, envoyez les fichiers).
2. Netlify > Add new site > Import from Git > choisissez le dépôt (netlify.toml configure tout).
3. Site configuration > Environment variables > ajoutez API_FOOTBALL_KEY = votre clé.
4. Redéployez (Deploys > Trigger deploy), puis Domain management > ajoutez pronosticdujour.com.
